# POCs

A collection of proof-of-concept projects. Each POC lives in its own folder with its own setup and README.

## Projects

| Folder | Description | Stack |
| --- | --- | --- |
| [`denmark-shop`](./denmark-shop) | Miracle Habesha Shop — localized demo storefront with loyalty/POS integration | Next.js 16, React 19, Tailwind v4, Zustand |

## Working on a POC

```bash
cd denmark-shop
npm install
npm run dev
```

See each project's README for details.
